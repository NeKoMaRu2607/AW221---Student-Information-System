# Pinnacle Academy — Student Information System (SIS)
### AW221 Web Application Development — Final Project

> 🌐 **Live Preview:** [portfolio-student-information-system.vercel.app](https://portfolio-student-information-system.vercel.app/)

> 📁 **Repository:** [NeKoMaRu2607/AW221---Student-Information-System](https://github.com/NeKoMaRu2607/AW221---Student-Information-System)

A web-based Student Information System built for **Pinnacle Academy** — a fictional higher-education institution. The system features a public-facing website and dedicated role-based portals for Admins, Teachers, Students, and Alumni, backed by PHP and MySQL.

---

## 🚀 How to Run Locally

### Front-end only (static pages)
```bash
git clone https://github.com/NeKoMaRu2607/AW221---Student-Information-System.git
cd AW221---Student-Information-System
# Open index.html in your browser
```

### Full stack (PHP + MySQL)
1. Install [XAMPP](https://www.apachefriends.org/) or use **Local by Flywheel**
2. Copy the project into your `htdocs/` folder
3. Import the database via **phpMyAdmin**
4. Start Apache + MySQL in XAMPP
5. Visit `http://localhost/AW221---Student-Information-System/`
